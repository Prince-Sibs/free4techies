# free4techies

Curated list of free developer tools, learning resources, and hosting options.

Quick start

- Open `index.html` in a browser to view the site.
- Add contributions by creating `contribution/resources.json` in a forked repo and opening a PR.

Repository structure

- `index.html` — site entry
- `css/` — styles
- `js/` — client scripts
- `public/resources.json` — merged resources used by the site
- `scripts/merge-resources.js` — merge helper used by CI
