free4techies is a curated directory of free developer tools, AI resources, hosting platforms, databases, learning materials, productivity apps, and design resources for developers, creators, and tech enthusiasts.

Built and maintained by Prince Sibanda.

## Quick start

- Open `index.html` in a browser to view the site.
- Add contributions by creating `contribution/resources.json` in a forked repository and opening a pull request.

## Explore categories

- AI & ML tools
- Development tools
- Hosting & deployment
- Databases & storage
- Design & UI resources
- Learning resources
- Productivity & collaboration tools

## Repository structure

- `index.html` — site entry and homepage
- `css/` — styles
- `js/` — client scripts
- `public/resources.json` — merged resources used by the site
- `scripts/merge-resources.js` — merge helper used in CI
